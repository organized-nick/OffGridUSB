# `bin/linux_arm64/` — Raspberry Pi 4/5 & ARM64 Linux Runtime

Populated automatically by `./scripts/download_internet_in_a_box.sh` or `DOWNLOAD_INTERNET_IN_A_BOX.bat`:

- `kiwix/kiwix-serve` & `kiwix-tools_linux-aarch64.tar.gz` — Static `aarch64` OpenZIM server (`:8081`)
- `llama-ubuntu-arm64.tar.gz` — Native ARM NEON/dotprod `llama-server` bundle (auto-extracted to `/tmp/emyrge_runtime/` on boot so `.so` symlinks work off `exFAT`/`FAT32` USB drives)
