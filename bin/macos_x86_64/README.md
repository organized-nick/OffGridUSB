# `bin/macos_x86_64/` — macOS Intel (x86_64) Runtime Slot

Optional dedicated Intel macOS binary directory (`kiwix-serve` / `llama-server`). When empty, Intel Macs automatically run Mozilla's Cosmopolitan polyglot binary in `../polyglot/llamafile.exe` via `/bin/sh`.
