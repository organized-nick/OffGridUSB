# `bin/macos_arm64/` — macOS Apple Silicon (M1–M4 Metal) Runtime

Populated automatically by `./scripts/download_internet_in_a_box.sh` or `DOWNLOAD_INTERNET_IN_A_BOX.bat`:

- `llama-macos-arm64.tar.gz` — Apple Silicon Metal-accelerated `llama-server` bundle (auto-extracted to `/tmp/emyrge_runtime/` on boot so `.dylib` symlinks work off `exFAT` USB drives)
- `kiwix/` — Optional macOS `kiwix-serve` slot
